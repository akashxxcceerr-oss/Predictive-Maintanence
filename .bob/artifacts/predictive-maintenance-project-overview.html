Problem & Dataset

Industrial machines fail unexpectedly, causing costly downtime. This project trains a multi-class classifier that predicts the type of failure from live sensor readings so maintenance teams can act proactively. Dataset: Kaggle – Machine Predictive Maintenance · 10 000 rows · no missing values · heavily imbalanced (≈96% No Failure).

Source Modules — src/

ModuleResponsibilities
data_preprocessing.py Load CSV, rename columns, encode categoricals, check quality, generate 4 EDA plots (failure distribution, correlation heatmap, speed vs torque scatter, tool wear histogram)
feature_engineering.py Add 4 derived features, stratified train/test split, fit & save StandardScaler
model_training.py Train RF, GB, LR, KNN; 5-fold CV; save all .joblib models; write metrics_summary.json; generate confusion matrices, model comparison bar chart, feature importances
evaluate.py SMOTE oversampling, GridSearchCV hyperparameter tuning, ROC-AUC curves, per-class P/R/F1 bar chart, save best_model_tuned.joblib + evaluation_report.json
ibm_watson_ml.py IBMWatsonMLClient: store model, create online deployment, score via endpoint. IBMCOSClient: upload/download to COS bucket. predict_local(): offline inference
